# 📖 About The Project

**AURUM** is a luxury fashion and lifestyle eCommerce landing page designed with a premium modern interface inspired by high-end fashion brands.

The project focuses on creating a visually attractive shopping experience with clean layouts, modern typography, elegant spacing, and responsive design principles.

This project was developed to improve frontend development skills and practice building real-world luxury brand interfaces using only HTML and CSS.
